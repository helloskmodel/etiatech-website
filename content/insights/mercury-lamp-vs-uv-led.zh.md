**一句话答案：** 汞灯是 200–600 nm 宽谱光源，兼容几乎所有配方、可提供 UVC、峰值辐照度最高，但需预热、有红外热与臭氧、寿命数千小时；UV LED 是 365–405 nm 单波长光源，能耗低、寿命数万小时、瞬时开关、无红外热无臭氧，但必须用 LED 配方。选择的第一依据是配方光谱，第二是热敏性与节拍。

*宽谱汞灯几乎兼容所有配方，LED 单峰必须与引发剂精确匹配。图片来源：Excelitas UV 固化选型指南。*

## 对比表

| 项目 | 汞灯（短弧／中压） | UV LED |
|---|---|---|
| 光谱 | 200–600 nm 宽谱，可滤光 | 单峰 ±10 nm |
| UVC | 有 | 无 |
| 峰值辐照度 | 点固化可达 37 W/cm² | 点固化 27.3 W/cm²，面固化 20 W/cm² |
| 寿命 | 短弧保证 2,000 h（典型 3,500–4,000 h）；中压约 1,000 h | 数万小时，产线已超 50,000 h |
| 开关 | 预热约 4 min，需快门 | 毫秒级，可脉冲 |
| 红外热 | 显著 | 无 |
| 臭氧／汞 | 有／含汞 | 无／无汞 |
| 功率调节 | 有限 | 5–100%，1% 步进 |
| 能耗 | 基准 | 降低 50% 以上 |
| 耗材 | 灯泡、快门、反射器 | 无 |
| 配方 | 几乎所有 | LED 专用 |

## 选汞灯的场景

需要 UVC 表面固化；已验证的传统配方不愿重新验证；极高峰值辐照度；研发阶段配方未定，需要一台机器覆盖全波段。

## 选 LED 的场景

配方为 365–405 nm 体系；基材热敏；节拍快、频繁启停；多点独立控制；降低能耗、排风与耗材成本；无汞环保要求。

## 混合使用

很多产线同时保留两者：LED 做主固化，汞灯做 UVC 补固化；或新品走 LED、老品保留汞灯。

**Q：从汞灯换 LED 要重新验证工艺吗？**

A：光谱变了，配方通常要换，工艺需重新验证。
