**一句话答案：** UV 固化是一种光化学工艺——油墨、涂层或胶粘剂中的光引发剂吸收特定波长的紫外光后产生自由基，引发聚合交联，材料在数秒内由液态变为固态；配方为 100% 固含、无 VOC，反应以秒计而非小时。

## 反应是怎么发生的

UV 固化配方由三部分组成：低聚物和单体（构成固化后的骨架）、光引发剂（吸收光后启动反应）、添加剂（颜料、流平剂等）。当光引发剂吸收到与其吸收谱匹配的 UV 能量，分子裂解产生自由基，自由基攻击单体双键引发链式聚合，几秒内形成三维交联网络。光一停，反应即止；光谱不匹配，反应根本不开始。

## 与热固化、溶剂干燥的区别

| 对比项 | UV 固化 | 溶剂型 / 热固化 |
|---|---|---|
| 时间 | 秒级 | 分钟至小时 |
| 固含 | 100%，无 VOC | 含溶剂 |
| 能耗 | 光源即开即停 | 烘道持续加热 |
| 基材 | 光源几乎不传热，适合塑料、薄膜 | 高温限制热敏基材 |
| 品质 | 耐刮擦、耐溶剂、粘接强，不良率低 | 受烘干均匀性影响 |
| 占地 | 光源模块几十厘米 | 烘道数米 |

## 用在哪里

电子组装（元件固定、灌封、三防）、光学光电子（透镜耦合、光纤连接器）、医疗器械（导管粘接、注射器、亲水涂层）、印刷包装（喷墨、标签）、汽车（车灯、传感器、显示屏）、光纤线缆（拉丝涂层）。

## 固化设备为什么决定成败

同一配方在不同光谱、辐照度、曝光时间下得到的硬度、附着力、表面固化程度都不同。选型指南明确指出：固化工艺对材料最终性能影响显著，设备是决定成品质量的关键环节。

## 常见问题

**Q：UV 固化会不会有残留单体？**

A：剂量足够且光谱匹配时转化率很高；表面欠固化多因氧阻聚，见[什么是氧阻聚](/insights/oxygen-inhibition-tacky-surface)。

**Q：不透光材料能 UV 固化吗？**

A：阴影区无法固化，需配合 UV + 湿气/热双固化配方。
