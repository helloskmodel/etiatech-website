**คำตอบหนึ่งประโยค:** การบ่มด้วยแสง UV (UV curing) คือกระบวนการเคมีแสง — สารเริ่มปฏิกิริยาด้วยแสง (photoinitiator) ในหมึก สารเคลือบ หรือกาว ดูดซับแสงอัลตราไวโอเลตที่ความยาวคลื่นจำเพาะ แล้วสร้างอนุมูลอิสระซึ่งกระตุ้นปฏิกิริยาพอลิเมอไรเซชันและการเชื่อมโยงข้าม ทำให้วัสดุเปลี่ยนจากของเหลวเป็นของแข็งภายในไม่กี่วินาที สูตร UV เป็นของแข็ง 100% ไม่มี VOC และปฏิกิริยาวัดเป็นวินาที ไม่ใช่ชั่วโมง

## ปฏิกิริยาเกิดขึ้นอย่างไร

สูตร UV ประกอบด้วยสามส่วน: โอลิโกเมอร์และโมโนเมอร์ (โครงสร้างหลักของฟิล์มหลังบ่ม), สารเริ่มปฏิกิริยาด้วยแสง (ดูดซับแสงแล้วเริ่มปฏิกิริยา) และสารเติมแต่ง (เม็ดสี สารช่วยไหล ฯลฯ) เมื่อสารเริ่มปฏิกิริยาดูดซับพลังงาน UV ที่ตรงกับสเปกตรัมการดูดกลืนของมัน โมเลกุลจะแตกตัวเป็นอนุมูลอิสระ อนุมูลอิสระโจมตีพันธะคู่ของโมโนเมอร์และเริ่มปฏิกิริยาลูกโซ่ สร้างโครงข่ายเชื่อมโยงข้ามสามมิติภายในไม่กี่วินาที แสงหยุด ปฏิกิริยาก็หยุด หากสเปกตรัมไม่ตรงกัน ปฏิกิริยาจะไม่เริ่มเลย

## ต่างจากการบ่มด้วยความร้อนและการอบแห้งตัวทำละลายอย่างไร

| รายการ | การบ่มด้วย UV | ตัวทำละลาย / ความร้อน |
|---|---|---|
| เวลา | วินาที | นาทีถึงชั่วโมง |
| ปริมาณของแข็ง | 100% ไม่มี VOC | มีตัวทำละลาย |
| พลังงาน | เปิด-ปิดแหล่งกำเนิดแสงทันที | เตาอบต้องให้ความร้อนต่อเนื่อง |
| วัสดุฐาน | แหล่งกำเนิดแสงแทบไม่ถ่ายเทความร้อน เหมาะกับพลาสติกและฟิล์ม | อุณหภูมิสูงจำกัดวัสดุที่ไวต่อความร้อน |
| คุณภาพ | ทนรอยขีดข่วนและตัวทำละลาย ยึดติดแน่น ของเสียต่ำ | ขึ้นกับความสม่ำเสมอของการอบ |
| พื้นที่ | โมดูลแสงไม่กี่สิบเซนติเมตร | เตาอบยาวหลายเมตร |

## ใช้ที่ไหนบ้าง

การประกอบอิเล็กทรอนิกส์ (ยึดชิ้นส่วน, potting, เคลือบป้องกัน), ออปติกส์และออปโตอิเล็กทรอนิกส์ (ต่อเลนส์, หัวต่อไฟเบอร์), อุปกรณ์การแพทย์ (ยึดสายสวน, กระบอกฉีดยา, เคลือบไฮโดรฟิลิก), การพิมพ์และบรรจุภัณฑ์ (อิงค์เจ็ท, ฉลาก), ยานยนต์ (โคมไฟ, เซนเซอร์, จอแสดงผล), ไฟเบอร์ออปติกและสายเคเบิล (เคลือบบนหอดึงเส้นใย)

## ทำไมอุปกรณ์บ่มจึงกำหนดผลลัพธ์

สูตรเดียวกันเมื่อบ่มด้วยสเปกตรัม ความเข้มแสง และเวลาที่ต่างกัน จะให้ความแข็ง การยึดเกาะ และการบ่มผิวที่ต่างกัน คู่มือเลือกผลิตภัณฑ์ระบุว่ากระบวนการบ่มมีผลอย่างมากต่อสมบัติทางกายภาพของวัสดุ ดังนั้นอุปกรณ์จึงเป็นปัจจัยชี้ขาดคุณภาพชิ้นงาน

## คำถามที่พบบ่อย

**Q: การบ่มด้วย UV มีโมโนเมอร์ตกค้างหรือไม่?**

A: หากปริมาณพลังงานเพียงพอและสเปกตรัมตรงกัน อัตราการเปลี่ยนสภาพจะสูงมาก ผิวที่บ่มไม่สมบูรณ์มักเกิดจาก[การยับยั้งด้วยออกซิเจน](/insights/oxygen-inhibition-tacky-surface)

**Q: วัสดุทึบแสงบ่มด้วย UV ได้หรือไม่?**

A: บริเวณเงาไม่สามารถบ่มด้วยแสงได้ ต้องใช้สูตร dual-cure แบบ UV + ความชื้น หรือ UV + ความร้อน
