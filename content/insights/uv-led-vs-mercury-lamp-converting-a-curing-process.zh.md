全球售出的 UV 点固化系统，如今已有一半以上是 LED。原因大家都熟：电耗只有几分之一、工件不发热、光源寿命长十倍、没有汞也没有臭氧。但很少有人说清楚：要让 LED 真正兑现这些数字，**工艺**里有什么必须跟着改。UV LED 不是换个灯泡那么简单，它是另一种光。本文按 Excelitas Noblelight 给自己客户写的转换 FAQ，加上 ETIA 在东南亚支持过的转换项目，把决定成败的六个差别逐一讲清。

## 1. 光引发剂必须对上波长

中压汞灯从约 250 nm 连续发射到 600 nm，在 UVB、UVC 都有很强的谱线。UV LED 只发一个近乎单色的窄带——365、385、395 或 405 nm，宽度 10–20 nm。多数为汞灯开发的光引发剂吸收峰在 UVB 和 UVC，恰恰是 LED 一点都不发的地方。

所以转换的第一个问题不在设备，在化学：**这款胶或涂料是不是按 LED 配的？** 如果不是，不管 LED 辐照度多高，它要么固化得很慢，要么根本不固化。解决办法是换用带长波光引发剂的配方，各大胶水厂现在都有同款产品的 LED 版本。测任何东西之前，先向供应商要 LED 牌号。

有一个例外反而省事：原本按铁掺杂或镓掺杂（金属卤化物）灯调配的配方，吸收本来就在 UVA，转到 LED 往往改动很小，因为那些灯本来就发在 LED 的波段。

## 2. 红外没了——而配方可能一直在靠它

中压汞灯大约 30–40% 的能量是红外。它加热工件，而这份热一直在默默干活：降低树脂粘度、加快反应动力学、帮固化走到底。LED 几乎不给这份热。

对热敏感的工件——导管接头、摄像模组、OLED 面板——这正是转 LED 的全部意义。但对一个一直白拿汞灯 20 °C 的配方，LED 固化出来可能比预期慢、比预期不彻底。补救在配方和剂量里，不要试图把热加回去。

## 3. 表面固化与氧阻聚

汞灯的短波 UVC 在涂层最上面几微米就被吸收，而那里正是空气中的氧与聚合反应竞争的地方。汞灯把表面固化得硬、不粘手；LED 只有长波，穿得更深，可能留下一个底下固化了、表面微粘的结果。

对接缝内部的胶这无所谓——没有暴露面。对涂层或外露的胶角就有关系，标准答案有三种：加胺协效剂或表面活性光引发剂的 LED 专用配方；固化区氮气保护；或者只为表面再过一道 254 nm 的短波光源。"LED 管深度、小弧灯管表皮"的混合线，在涂装和印刷里很常见。

## 4. 线速与工艺窗口

能不能保持原线速，取决于两点：LED 配方反应性多高，LED 在工作距离上实际给多少辐照度。剂量 = 辐照度 × 时间；曝光时间减半，辐照度就得加倍才能维持同一剂量。

实用方法是先在台面上把工艺窗口做出来，再碰产线：在真实工作距离测辐照度，找出完全固化（硬度、拉力或 FTIR 判定）的最小剂量，再加安全余量。把窗口换算成线速就是算术。许多行业是全速转换的——单张和卷筒印刷机都在其列——但每种配方都有自己的窗口，窗口不能从汞灯工艺照搬。

## 5. 黄变与颜色

长波光引发剂容易泛黄，而为了少泛黄降低用量，固化也跟着变慢。对结构胶无所谓；对白底上的清漆、光路里的光学胶，这是规格项。手段是光引发剂选型（常用复配）、波长略短（365 nm 而不是 395 nm），以及在真实基材上按真实老化条件做测试。

## 6. 你的辐射计多半读不了 LED

给汞灯做的辐射计，光谱响应是围绕 UVA/UVB/UVC 设计的；对着 395 nm LED 会读出个数，但不是正确的数。用旧表把 LED 工艺和原汞灯工艺比，得到的是精确、可重复、并且错误的数字。

要用为 LED 波段（RadTech 北美称为 UVA2，365–405 nm）设计并按 LED 波长校准的辐射计。OmniCure 的 LS200 就是为 LX500 LED 灯头做的；R2000 留给 S 系列汞灯。按周期校验——每周或每月都正常——并记录读数和日期；LED 不像汞灯那样衰减，但光学件会脏，工作距离会悄悄漂。

## 不变的东西

每次转换都会冒出两个担心，其实都不成立。一班里开关 LED 很多次不缩短寿命；调暗运行也不缩短。LED 胶固化到位后不比汞灯固化的弱——粘接强度在配方和剂量里，不在光源里。

## 转换清单

1. 向供应商要你这款胶或涂料的 LED 牌号。
2. 按光引发剂选波长——胶通常 365 或 385 nm，有色或厚层 395 或 405 nm。
3. 用 LED 辐射计在真实工作距离测辐照度。
4. 在台面上确定完全固化的最小剂量，再加余量。
5. 检查表面：不粘手吗？需不需要氮气保护或第二光源？
6. 若胶层或涂层外露，做颜色老化测试。
7. 把剂量换算成线速，先跑试产批次再改产线。
